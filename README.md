# افزونه حالت تاریک ادوبی کانکت | Adobe Connect Dark Mode Extension

یک افزونه پیشرفته و مستقل مبتنی بر **Manifest V3** برای مرورگرهای Chrome و Edge جهت ایجاد حالت تاریک (Dark Mode) استاندارد و باکیفیت در نسخه وب Adobe Connect، بدون آسیب رساندن یا اینورت کردن محتوای حساس جلسه (وبکم، اشتراک صفحه، اسلایدها و وایت‌برد).

## ویژگی‌های کلیدی (Key Features)

1. **طراحی لایه‌ای دوگانه (Dual-Layer Engine):**
   - **Layer 1 (تشخیص هوشمند و محافظه‌کارانه عمومی):** ارزیابی پویای روشنایی (Luminance BT.601) پس‌زمینه‌ها و متن‌ها برای بخش‌های عمومی بدون ایجاد تخریب بصری.
   - **Layer 2 (سلکتورهای اختصاصی ادوبی کانکت):** استایل‌دهی دقیق به هدر بالا، نوار ابزارها، پادهای چت (Chat)، شرکت‌کنندگان (Attendees)، یادداشت‌ها (Notes)، پرسش و پاسخ (Q&A)، نظرسنجی (Poll)، منوها و کامپوننت‌های سیستم طراحی Adobe Spectrum.
2. **عدم استفاده از فیلترهای مخرب:**
   - به هیچ وجه از `filter: invert(...)` روی کل صفحه یا کانتینرهای عمومی استفاده نمی‌شود.
   - از اعمال کورکورانه استایل با `* { background: ... }` اجتناب شده است.
3. **حفاظت قطعی از عناصر چندرسانه‌ای و آموزشی (Media Preservation):**
   - تمامی تگ‌های `video` (وبکم و وبینار)، `canvas` (وایت‌برد و ارائه‌ها)، `img`، `picture`، اسلایدهای SVG و فایل‌های به اشتراک‌گذاشته‌شده بدون تغییر و با رنگ‌های طبیعی باقی می‌مانند.
4. **عملکرد سبک و بهینه (Performance-Optimized SPA Observer):**
   - استفاده از `MutationObserver` سبک مجهز به مکانیزم Debounce (تاخیر ۶۰ میلی‌ثانیه) و پردازش دسته‌ای جهت پشتیبانی از ماهیت تک‌صفحه‌ای (SPA) ادوبی کانکت و اضافه شدن پویای چت‌ها یا پنجره‌ها بدون افت فریم (FPS).
5. **پشتیبانی از Open Shadow DOM:**
   - شناسایی خودکار ریشه‌های شادودام باز (Open Shadow Roots) و تزریق ایمن شیوه‌نامه‌ها به آنها.
6. **فعال‌سازی اختصاصی بر اساس دامنه (Per-Domain Whitelist):**
   - افزونه تنها روی دامنه‌هایی فعال می‌شود که کاربر صراحتاً در پنجره پاپ‌آپ آن را روشن کرده باشد (مناسب برای سرورهای دانشگاهی و سازمانی اختصاصی مانند `lms.*`, `vc.*`, `connect.*`).
   - وضعیت فعال‌سازی هر دامنه در `chrome.storage.local` ذخیره شده و پس از Refresh صفحه یا بستن مرورگر پایدار می‌ماند.
7. **حفظ حریم خصوصی کامل:**
   - فاقد هرگونه تله‌متری، ترکر، یا درخواست به سرورهای خارجی. کدها ۱۰۰٪ لوکال اجرا می‌شوند.

## معماری افزونه (Extension Architecture)

معماری افزونه به صورت ماژولار و تفکیک‌شده طراحی شده است:

```
┌────────────────────────────────────────────────────────┐

│   (popup.html / popup.css / popup.js)                  │
│   - Domain Detection & Switch State                    │

└───────────┬────────────────────────────────────────────┘
            │ chrome.storage.local & chrome.tabs.sendMessage
            ▼
┌────────────────────────────────────────────────────────┐
│             Background Service Worker                  │
│   (background.js - Manifest V3)                        │
│   - Lifecycle Management & Default State               │
│   - Dynamic Action Badge (displays 'ON' when active)   │
└────────────────────────────────────────────────────────┘
            │
            ▼ Content Script Injection
┌────────────────────────────────────────────────────────┐
│                     Content Layer                      │
│                                                        │
│  ┌────────────────┐  ┌───────────────┐  ┌────────────┐ │
│  │   content.js   │  │theme-engine.js│  │observer.js │ │
│  │ (Domain check, │◄─┼─(Injects CSS, ┼─►│(Debounced  │ │
│  │ Storage & Msg) │  │ Layer 1 & 2)  │  │DOM watcher)│ │
│  └────────────────┘  └───────┬───────┘  └────────────┘ │
└──────────────────────────────┼─────────────────────────┘
                               ▼
┌────────────────────────────────────────────────────────┐
│                     Styles Layer                       │
│  - variables.css      : Design tokens & CSS vars       │
│  - base.css           : Root, scrollbars, media safety │
│  - adobe-connect.css  : Layer 2 specific selectors     │
│  - components.css     : Menus, modals, popovers, tabs  │
└────────────────────────────────────────────────────────┘
```

## راهنمای نصب (Installation Guide)

### نصب در گوگل کروم (Google Chrome)

1. مرورگر **Chrome** را باز کنید.
2. به آدرس زیر بروید:
   ```text
   chrome://extensions/
   ```
3. در گوشه بالا سمت راست، گزینه **Developer mode** را فعال کنید.
4. روی دکمه **Load unpacked** (بارگیری بازنشده) در بالا سمت چپ کلیک کنید.
5. پوشه پروژه را انتخاب کنید:
   ```text
   d:\Alirezas-project\Adobe Connect Dark Mod Ext
   ```
6. افزونه با نام **Adobe Connect Dark Mode** به لیست افزونه‌های شما اضافه خواهد شد.
7. آیکون پین (Pin) کنار نام افزونه را بزنید تا در نوار ابزار مرورگر همیشه در دسترس باشد.

### نصب در مایکروسافت اج (Microsoft Edge)

1. مرورگر **Edge** را باز کنید.
2. به آدرس زیر بروید:
   ```text
   edge://extensions/
   ```
3. از منوی سمت چپ، گزینه **Developer mode** (حالت توسعه‌دهنده) را فعال کنید.
4. روی دکمه **Load unpacked** کلیک کنید.
5. پوشه افزونه را انتخاب کنید:
   ```text
   d:\Alirezas-project\Adobe Connect Dark Mod Ext
   ```
6. افزونه با موفقیت لود شده و آماده استفاده است.

## نحوه استفاده و فعال‌سازی (Usage Guide)

1. وارد کلاس یا جلسه وب **Adobe Connect** خود شوید (فرقی نمی‌کند روی دامنه رسمی `adobeconnect.com` باشد یا سرور اختصاصی دانشگاه مانند `lms.ut.ac.ir` یا `vc.sharif.edu`).
2. روی آیکون ماه افزونه در نوار ابزار (Toolbar) کلیک کنید.
3. در پنجره پاپ‌آپ باز شده:
   - نام دامنه فعلی را مشاهده می‌کنید (مثلاً `connect.example.com`).
   - سوییچ **Dark Mode** را در حالت **ON** قرار دهید.
4. تم تاریک بلافاصله و بدون نیاز به رفرش روی صفحه اعمال می‌شود!
5. پس از خروج، بستن تب یا Refresh صفحه (F5)، تم تاریک همچنان به صورت پایدار و خودکار فعال باقی می‌ماند.
6. در صورتی که خواستید تنظیمات دامنه پاک شود، دکمه **Reset Site / بازنشانی دامنه** را در پاپ‌آپ بزنید.

## نحوه دیباگ و بررسی خطاها (Debugging Guide)

### ۱. دیباگ پاپ‌آپ (Popup UI):
- روی آیکون افزونه در تولبار راست‌کلیک کرده و گزینه **Inspect popup** را انتخاب کنید.
- در تب Console می‌توانید لاگ‌های مربوط به شناسایی دامنه و تغییرات استوریج را بررسی کنید.

### ۲. دیباگ کدهای داخل صفحه (Content Scripts):
- در تب Adobe Connect، کلید `F12` را فشار دهید تا Chrome DevTools باز شود.
- به تب **Console** بروید. هیچ خطایی نباید توسط افزونه لاگ شده باشد.
- با نوشتن دستور زیر می‌توانید وضعیت فعال بودن تم را بررسی کنید:
  ```javascript
  document.documentElement.getAttribute('data-acd-theme'); // باید خروجی "dark" بدهد
  ```

### ۳. دیباگ سرویس‌ورکر (Background Service Worker):
- در صفحه `chrome://extensions/`، زیر نام افزونه، روی لینک آبی‌رنگ **service worker** کلیک کنید تا کنسول اختصاصی پس‌زمینه باز شود.

## محدودیت‌های نسخه اولیه (V1 Limitations)

نسخه ۱.۰ به عنوان **فونداسیون استاندارد و پایدار** پیاده‌سازی شده است:
1. **تنوع نسخه‌های سرور Adobe Connect:** برخی دانشگاه‌ها از Adobe Connect نسخه ۹، ۱۰، ۱۱ یا ۱۲ استفاده می‌کنند. ساختار کدهای کلاینت HTML5 در هر نسخه ممکن است کمی در نام کلاس‌های CSS تفاوت داشته باشد.
2. **پادهای سفارشی قدیمی (Legacy Custom Pods):** پادهایی که از طریق فلش قدیمی یا با فریمورک‌های متفرقه درون iframe جداگانه لود شوند و سورس آنها خارج از دامنه کلاس باشد ممکن است به سلکتورهای لایه ۲ اختصاصی بیشتری نیاز داشته باشند.
3. **وایت‌برد و ارائه‌ها:** رنگ متون رسم‌شده داخل بوم وایت‌برد (Whiteboard Drawing) به عمد دستکاری نمی‌شود تا رنگ واقعی قلم استاد (مثلاً قرمز یا آبی) مخدوش نشود.

## راهنمای توسعه به V2: نحوه ارسال DOM و اسکرین‌شات

برای اینکه در نسخه بعدی (V2) تم تاریک را برای نسخه خاص Adobe Connect سازمان یا دانشگاه شما ۱۰۰٪ بدون نقص و دقیق‌تر کنیم:

### ۱. چه اسکرین‌شات‌هایی ارسال کنید؟
- اسکرین‌شات از نمای کامل جلسه که در آن پاد چت، پاد لیست افراد، پاد یادداشت و نوار بالای صفحه دیده شود.
- اگر بخشی هنوز زمینه سفید دارد، دور آن یک خط قرمز بکشید.

### ۲. چگونه کدهای DOM آن بخش را استخراج و ارسال کنید؟
1. در صفحه Adobe Connect، روی المانی که هنوز سفید است یا رنگ نامناسبی دارد راست‌کلیک کرده و گزینه **Inspect** (بررسی عنصر) را بزنید.
2. در پنل Elements در DevTools، روی تگ مورد نظر راست‌کلیک کنید:
   - مسیر: **Copy > Copy outerHTML**
3. همچنین در همان پنل، تب **Styles** و تب **Computed** را ببینید:
   - ویژگی `background-color` و `color` مربوط به کدام کلاس است؟ (مثلاً `.pod-main-view` یا `.spectrum-Dialog`).
4. نام کلاس‌ها یا قطعه کدهای کپی‌شده را ارسال کنید تا در فایل [styles/adobe-connect.css](file:///d:/Alirezas-project/Adobe%20Connect%20Dark%20Mod%20Ext/styles/adobe-connect.css) سلکتور اختصاصی و دقیق آن اضافه شود.
